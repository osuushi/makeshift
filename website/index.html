Making CAD easier to use

Makeshift is for people who want to design and make things, including people who have never used CAD. We want to make the tools easier to learn and give you help with the routine work that comes with a project.

Learn while you work

You can start by drawing a shape and dragging it to the size you want. Selecting it shows the controls for editing it, and you can type in dimensions when you need an exact size. These are the same tools you’ll use as you take on more involved projects.

Edit shapes directly

Makeshift works directly with solid geometry, so you can add or remove material, move a face, or round an edge on the part you’re working on. You can make changes as you go without planning a feature tree in advance.

Get help from a coding agent

If a task involves a lot of repetition or calculation, you can ask a coding agent to help. In the desktop app, the agent can inspect your model and write scripts to edit it. You can then adjust the result with the regular tools or undo the script’s changes.

Connect a separately installed coding agent. Its account and any service costs are separate from Makeshift.

Add details with decorators

Decorators add details such as screw threads, knurling, and gear teeth while keeping the underlying shape simple to edit. You can adjust their settings as you work, and the details are included when you export a mesh for printing. The embedded coding agent can also write custom decorators for your project.

A tool you can
make your own.

Makeshift costs nothing to use. The source is available to study, change, and share under the LGPL. You can build it yourself, improve it, or take it in a different direction.

Your work saves to local files. Export STEP for solid geometry, or STL and 3MF for printing and other mesh workflows.
